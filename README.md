# AutoService

Учебный проект по дисциплине «Жизненный цикл разработки программного обеспечения».

## Сведения о проекте

- **Автор:** Кожемякин Владислав Олегович, гр. 434701
- **Преподаватель:** Внук О. М.
- **Тема проекта:** Автосервис (AutoService)
- **Тип проекта:** клиент-серверное мобильное приложение (клиент Qt Quick, сервер Cloud API, базы данных PostgreSQL и SQLite)
- **Язык разработки:** C++17 / QML (Qt Quick), система сборки CMake
- **Внешние сервисы:** NHTSA VIN API (декодирование VIN), сервис курсов валют (BYN/USD), сервис Push-уведомлений

## Описание проекта

**AutoService** — программная система для автоматизации взаимодействия клиентов и персонала станции технического обслуживания (СТО).

Основные возможности системы:
- ролевой доступ (RBAC) для клиента, мастера СТО и администратора СТО с аутентификацией по JWT;
- ведение личного гаража и добавление автомобилей по 17-значному VIN-коду через NHTSA VIN API с учётом коэффициента типа кузова;
- выбор услуг автосервиса (ремонт и ТО, мойка, антикоррозийная обработка, покраска, чип-тюнинг) и автоматический расчёт стоимости и длительности работ с комплексной скидкой;
- запись на свободное время по постам (боксам) с возможностью отмены и переноса не позднее чем за 2 часа;
- отслеживание статуса обслуживания в реальном времени и согласование дополнительных работ;
- хранение истории ремонтов (облачная БД PostgreSQL + локальный кэш SQLite) и экспорт электронной сервисной книжки в форматах JSON и PDF;
- панель мастера СТО для управления статусами заказа и панель администратора для настройки тарифов, боксов и учётных записей персонала.
