# AutoService

Учебный проект по дисциплине «Жизненный цикл разработки программного обеспечения».

## Сведения о проекте

- **Автор:** Кожемякин Владислав Олегович, гр. 434701
- **Преподаватель:** Внук О. М.
- **Тема проекта:** Автосервис (AutoService)
- **Тип проекта:** клиент-серверное мобильное приложение (клиент Qt Quick, сервер Cloud API, базы данных PostgreSQL и SQLite)
- **Язык разработки:** C++17 / QML (Qt Quick), система сборки CMake
- **Внешние сервисы:** NHTSA VIN API (декодирование VIN), сервис Push-уведомлений (FCM/APNs)

## Описание проекта

**AutoService** – программная система для автоматизации взаимодействия клиентов и персонала станции технического обслуживания (СТО).

Основные возможности системы (релиз v1.0):
- ролевой доступ (RBAC) для клиента, мастера СТО и администратора СТО с аутентификацией по JWT;
- ведение личного гаража и добавление автомобилей по 17-значному VIN-коду через NHTSA VIN API с учётом коэффициента типа кузова;
- выбор услуг автосервиса (ремонт и ТО, мойка, антикоррозийная обработка, покраска, чип-тюнинг) и автоматический расчёт стоимости (BYN) и длительности работ с комплексной скидкой 10%;
- запись на свободное время по постам (боксам) с ACID-защитой от двойной записи и возможностью отмены/переноса не позднее чем за 2 часа;
- отслеживание статуса обслуживания в реальном времени, согласование дополнительных работ с **фотоотчётом мастера** (1–3 фото) и автоматические **напоминания о плановом ТО**;
- хранение истории ремонтов (облачная БД PostgreSQL + локальный read-only кэш SQLite) и экспорт электронной сервисной книжки в формате JSON;
- панель мастера СТО для управления статусами заказа и панель администратора для настройки тарифов, боксов, учётных записей персонала и индикатора загрузки СТО.
